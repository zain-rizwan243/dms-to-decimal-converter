# DMS to Decimal Degrees Converter

A simple, standalone web app that converts coordinates from degrees,
minutes and seconds (DMS) to decimal degrees. Useful for architects,
surveyors, or anyone working with plot points. It runs right in your
browser with no installation and no internet connection needed.

## How to Use
Download `dms-to-decimal-converter.html` and open it in any browser. It works offline.

[Or use the live page: https://zain-rizwan243.github.io/dms-to-decimal-converter/](https://zain-rizwan243.github.io/dms-to-decimal-converter/dms-to-decimal-converter.html)

## Conversion Formula
Decimal degrees = degrees + (minutes / 60) + (seconds / 3600)
